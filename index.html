      AI board

      In TERM (or I1TERM), ATDT AI calls a BBS whose sysop is DeepSeek V4.1 Flash: chat with it, or with the Bastard Operator From Hell (who may hang up on you), or order a program in BASIC or Z80 that it writes, tests on a spare Spectrum and sends by ZMODEM to your tape, or upload a BASIC program of yours from tape (EXTEND, then U, in TERM) to have it fixed. It needs your own DeepSeek API key.

      No key yet.
      How do I get a key?
      1. Open platform.deepseek.com and sign up.
      2. Add a little credit on Top up; with no balance, calls fail with "insufficient balance".
      3. Open API keys, create one named "K-Prompt" and copy it (it starts with sk-).
      4. Paste it above and press Save, or type it when the board asks.
      5. Load TERM from the shelf, then ATDT AI.

      The key stays in this browser and goes only to api.deepseek.com; calls are billed to your DeepSeek account. Forget removes it.

      Controls

      The keys are the machine's own: a letter at the start of a line is a keyword (on a ZX81 P is PRINT, J LOAD, R RUN, S SAVE, A NEW, K LIST; on a ZX80 O is PRINT, W LOAD, E SAVE). Symbols type as SHIFT + their key.

      Modem

      Carrier

      A Hayes modem that dials telnet BBSes. Load TERM.tap from the shelf for a 64-column terminal, then ATI lists the boards and ATDT 1 dials the first. Home (EDIT) goes back to BASIC with the call up; RUN 20 returns. From BASIC: IN 447 is the status, IN 703 and OUT 703,x the data.

      Type in a listing

      Paste a BASIC program, one numbered line per line, as a magazine printed it. Keywords become the Spectrum's tokens (GOTO and GO TO both work); it goes onto a tape and loads with LOAD "".
